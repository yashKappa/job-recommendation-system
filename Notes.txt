## **3. How It Works (Flow)**

1. **Frontend (React)**

   * User logs in → Resume URL fetched from Firebase → Displayed on page.
   * User clicks "Analyze Resume" → Sends URL to Flask backend API `/analyze-resume`.

2. **Backend (Flask)**

   * Downloads resume from URL.
   * Calls `resume_parser.extract_text` → gets plain text from PDF/DOCX.
   * Calls `resume_analyzer.analyze_resume` → returns:

     * **Email**
     * **Skills** (matched from `skills.json`)
     * **Keywords** (top 20 nouns/proper nouns)
   * Returns JSON response to frontend.

3. **Frontend**

   * Receives JSON → Displays analysis in the UI.

## **4. Notes / Observations**

* `resume_analyzer.py` now uses **regex with word boundaries** to avoid false positives like detecting `c` inside `oracle`.

* Frontend currently supports **PDF and image resumes**, but not DOCX in preview (though backend can process DOCX).
* Skills detection depends on `skills.json`. If a skill in resume isn’t in `skills.json`, it won’t show up.
